# 🌳 Rubber Yield – Ensemble Learning Model Comparison

A machine learning project that compares different regression, ensemble, and hybrid learning techniques to predict monthly rubber production in Sri Lanka.

The project aims to identify how different machine learning approaches perform when predicting **Total Rubber Production (MT)** using historical year and month information.

## 📌 Project Overview

This project explores and compares six machine learning approaches:

| Category | Models |
|---|---|
| Single Models | Random Forest, XGBoost |
| Ensemble Models | Voting Regressor, Stacking Regressor |
| Hybrid Models | Hybrid RF + ARIMA, Hybrid RF + ANN |

The models use historical monthly rubber production data from **2000 to 2023**.

The dashboard provides:
- Model performance comparison using MAE, RMSE, MAPE, and R².
- Actual vs. predicted production visualization.
- Monthly forecast comparison.
- Feature importance analysis.
- Dataset statistics and methodology details.

## 📊 Dataset

**Dataset:** `Dataset_of_Rubber.xlsx`

- Coverage: 2000–2023
- Frequency: Monthly
- Number of observations: 288
- Prediction target: `Total (MT)`
- Input features: Year and Month, with sine and cosine transformations of the month to represent seasonality.

The product-level columns are retained in the source dataset but are not used as model inputs.

## 🧠 Model Evaluation Methodology

To preserve the chronological order of the time-series data, the dataset is divided as follows:

| Dataset | Period | Purpose |
|---|---|---|
| Training | 2000–2017 | Model training |
| Validation | 2018–2020 | Hyperparameter tuning |
| Testing | 2021–2023 | Final evaluation |

The models are evaluated using:

- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **MAPE:** Mean Absolute Percentage Error
- **R²:** Coefficient of Determination

Additional walk-forward cross-validation is performed to examine model performance across multiple time windows.

## 🚀 Getting Started

Follow these steps to clone and run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/navodachathurya/Rubber-Yield---Ensemble-Model-Comparison.git
```

Navigate into the project directory:

```bash
cd Rubber-Yield---Ensemble-Model-Comparison
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the Models

Open the Jupyter Notebook:

```bash
jupyter notebook rubber_ensemble_model.ipynb
```

Alternatively, open the notebook using VS Code.

Run all notebook cells from beginning to end.

This step:
- Loads and preprocesses the dataset.
- Performs exploratory data analysis.
- Tunes model hyperparameters.
- Trains and evaluates all six models.
- Performs walk-forward cross-validation.
- Generates feature importance visualizations.
- Saves trained models and metadata into the `artifacts/` directory.
- Generates the shared `common.py` module.

**Important:** Run the notebook successfully before starting the dashboard.

### 4. Run the Streamlit Dashboard

After model training and artifact generation, start the dashboard:

```bash
streamlit run app.py
```

The dashboard will be available at:

```text
http://localhost:8501
```

## ⚠️ Important Considerations

- The models use only Year and Month-derived features; they do not account for external factors such as rainfall, temperature, labour availability, or cultivated land area.
- Tree-based models such as Random Forest and XGBoost cannot naturally extrapolate beyond the training period. Their future predictions may remain relatively flat.
- R² can be misleading when the test period has very little variation in actual production. Therefore, MAE, RMSE, and MAPE should also be considered.
- The forecasts are experimental outputs for academic model comparison and should not be treated as reliable real-world production forecasts.

## Interpretation

In this project, Hybrid RF + ANN performed the best in the main test set, achieving the lowest RMSE of 39.1 MT. I think it performed well because ANN learns the main production pattern, while Random Forest helps to correct the remaining errors. However, I also used MAE and MAPE because R² alone is not enough to evaluate model performance, especially when actual production values have very little variation. In walk-forward validation, Hybrid RF + ARIMA achieved the lowest average RMSE. Therefore, the best model can depend on the evaluation period.
